# Zoho Sync Integration

Synchronizes data between AmCare OS and Zoho CRM/Books.

## Features

- **Bidirectional Sync**: Sync contacts, invoices, and payments
- **Automated**: Scheduled synchronization
- **Error Handling**: Robust error handling and retry logic
- **Audit Trail**: All sync operations logged

## Configuration

Set environment variables:
- `ZOHO_CLIENT_ID`
- `ZOHO_CLIENT_SECRET`
- `ZOHO_REFRESH_TOKEN`

## Usage

```bash
npm run sync
```
