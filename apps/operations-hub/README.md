# Operations Hub

Payment processing, appointment scheduling, and integration management.

## Features

- **Payments**: Process and track payments
- **Appointments**: Schedule and manage appointments
- **Integrations**: Manage external service connections
- **Billing**: Billing and invoicing management
- **Settings**: System configuration

## Development

```bash
npm run dev
```

Runs on port 3003 (configurable via OPERATIONS_HUB_PORT)
