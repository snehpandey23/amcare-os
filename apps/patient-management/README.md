# Patient Management

Patient tracking, secure messaging, form management, and patient records.

## Features

- **Patient Tracker**: Search and manage patient records
- **Secure Chats**: HIPAA-compliant messaging with patients
- **Forms**: Digital form management and collection
- **Patient Records**: Comprehensive patient information
- **Appointments**: Schedule and manage appointments

## Development

```bash
npm run dev
```

Runs on port 3002 (configurable via PATIENT_MANAGEMENT_PORT)
