# Netlify deployment — deprecated

**Production hosting for Siya Health is Vercel-only.**

- Redirects and clean URLs: `vercel.json`
- Build: `npm run build` (see `package.json`)
- Deploy: `npm run deploy` (Vercel CLI)

This file and `netlify.toml` are kept for historical reference. Do not deploy to Netlify without restoring a full redirect set from `vercel.json`.
