# Siya Health – Image assets

Placeholder SVGs are used so the site works without external assets.

**To use real photos:** add JPGs with these names and update `index.html` to use `.jpg`:

- `hero-telehealth.jpg` – hero section
- `adhd-care.jpg` – ADHD Care service card
- `weight-loss.jpg` – Medical Weight Loss service card
- `concierge-care.jpg` – Concierge Primary Care service card
- `patient-testimonial.jpg` – testimonial portrait (square crop works best)

All images use `max-width: 100%`, `border-radius: 12px`, and `object-fit: cover` for responsive layout.
