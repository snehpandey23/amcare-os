# Zoho Common — Siya Health marketing assets

Staging folder for assets intended for the **Zoho WorkDrive Common** team folder (TrueSync path on local machines typically under `ZohoWorkDriveTrueSync-AmcareMedicalConsultancyIndiaPvtLtd`).

Upload or sync contents of `static-posts/` into WorkDrive **Common → static-posts** (or the team’s preferred Common marketing path).

## Standards

All packages must follow `docs/SIYA-STANDARDS.md` and `data/site-standards.mjs`:

- Education primary CTA = **Read the Health Guide** (on-image OK)
- Booking labels = exact **Talk to a Clinician** (CarePatron) / ADHD funnel **Book ADHD Evaluation**
- No Meet & Greet, Find the Right Starting Point, Start Here, Join Waitlist, Book with {Name}
- Physician-led telehealth · not psychiatry · screening ≠ diagnosis · medication never guaranteed
- Siya Circle never as post primary CTA

## Layout

```
zoho-common/
  static-posts/
    adhd-in-women/
      …
```

Each post package includes creative PNGs plus a `CAPTIONS.md` with channel-ready copy.
