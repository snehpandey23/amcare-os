# Siya Brand OS — Anti-Patterns

**Status:** Companion to Brand OS (not a parallel constitution)  
**Use:** Fast teaching for designers, marketers, and AI — *what not to do* and why  
**Parents:** [`01-BRAND-OS.md`](./01-BRAND-OS.md) · [`02-VISUAL-LANGUAGE.md`](./02-VISUAL-LANGUAGE.md)

These are mistakes Siya has already learned from (or that healthcare marketing defaults to). If a draft matches an entry here, revise before ship.

**Scope:** Keep this file lean (~30–40 entries forever). Every entry should have been painful enough that someone remembers *why* it’s here. Document only mistakes that violate Brand OS — not generic design advice (“don’t use Comic Sans”). If it isn’t a Siya-specific lesson, delete it.

---

## Photography & people

| Anti-pattern | Why it fails |
| --- | --- |
| Stock doctor shaking hands | Says “generic healthcare,” not recognition |
| Arms-crossed white-coat stare | Corporate headshot energy; fights Care before company |
| AI-generated people pretending to be clinicians | Breaks trust permanently; never “real clinicians, real conversations” |
| Clipboard / stethoscope prop portraits | Hospital brochure cliché |
| Collages and floating avatar stacks | Dilutes one dominant human per beat |
| Competitor telehealth stock (Wellspring / MedConnect / Power Telehealth style) | Off-brand; often recognizable as rented imagery |

---

## Above the fold / layout

| Anti-pattern | Why it fails |
| --- | --- |
| Twenty trust badges above the fold | Competes with recognition; badges ≠ trust |
| Twin identical primary CTAs in one section | Hierarchy collapse |
| Dark frosted “consultant” glass cards over heroes | Cold, trendy, not editorial care |
| Sticky bar + chat + hero CTA all fighting on first paint | Anxiety, not calm confidence |
| Section · section · section with no whitespace | Hospitals do this; Siya does not |
| Card wrapping every paragraph | Decoration for decoration’s sake |

## Urgency & fear

| Anti-pattern | Why it fails |
| --- | --- |
| Red countdown timers | Manufactured anxiety |
| “Limited time” offers without a genuine clinical or operational reason | Fake urgency; Brand OS forbids it |
| Fear-based headlines | Converts through panic; Siya converts through clarity |
| Scare imagery invented for ads | Urgency must come from medicine, not marketing |

---

## Language & education

| Anti-pattern | Why it fails |
| --- | --- |
| Medical jargon where plain language exists | Confusion is the enemy |
| Screening language that implies diagnosis or a guaranteed prescription | Clinical + legal failure |
| Miracle timelines / “results like these” | Exaggeration; trust does not compound |
| Starting with “We treat X” before “Does this sound familiar?” | Skips recognition |

## Graphics & social

| Anti-pattern | Why it fails |
| --- | --- |
| Emoji-heavy educational graphics | Looks like a wellness app, not a practice |
| Overloaded carousels (many fonts, fifteen icons) | Starts at decoration instead of message |
| Blue / purple SaaS gradients as identity | Generic telehealth template debt |
| Glow effects, blobs, neumorphism, animated backgrounds | Trend debt; won’t feel premium in five years |
| Oversized cute medical illustrations as the main visual | Illustrations stay minimal; photography carries recognition |
| Inventing a new layout every post | Use creative families (Recognition / Explanation / Proof / Action) once `04` exists |

---

## Trend debt

> **Avoid borrowing aesthetics that are fashionable but disconnected from Siya’s principles. Trends expire faster than trust.**

| Anti-pattern | Why it fails |
| --- | --- |
| Copying Apple’s current hero | Apple’s brand evolves. Siya shouldn’t chase it. |
| Copying Linear’s illustrations | Their product isn’t yours. |
| Copying health startups because they raised funding | Funding isn’t evidence of good communication. |
| Designing for Dribbble instead of patients | Beautiful isn’t automatically understandable. |
| Blue / purple SaaS gradients, glow, glass-as-identity | Already listed above — same debt class |

## Process anti-patterns

| Anti-pattern | Why it fails |
| --- | --- |
| Starting with “Which background?” | Wrong end of the creative hierarchy |
| Treating Homepage redesign as a brand rewrite | Website is implementation #1; Brand OS is the constitution |
| Following `CURSOR-MASTER-PROMPT.md` for new work | Deprecated denser card/emoji/ATF language |
| Casually editing Brand OS principles mid-sprint | Preferences ≠ principles; version or don’t |
| Encoding incomplete rules into AI mega-prompts | AI guide comes last and *orchestrates* SoTs |
| Optimizing every creative solely for CTR | High clicks can coexist with low trust. Brand OS optimizes for long-term trust first, then performance. |
| Adding one more badge, CTA, testimonial, section, icon, or animation because “it might help” | Most pages improve by subtraction. Simplicity is a design decision, not an absence of effort. |

## Quick reject test

If the draft does any of the following, stop:

1. Manufactures anxiety to convert  
2. Puts decoration above recognition  
3. Makes the platform louder than the care relationship  
4. Looks like it could belong to any telehealth SaaS after removing the logo  

Then return to Brand OS → Visual Language → (when live) Creative System.
