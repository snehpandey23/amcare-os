# Video prompts — Siya Health

Reel / short-form scripts for HeyGen and similar tools. **Prompts and scripts only — not rendered MP4 in git unless a pack ships a ready file.**

## Pack convention

```text
editorial-packs/[Insight-ID]/video/video-prompt.md
```

Include:
1. Opening hook  
2. Key points (synthesized — not pasted research notes)  
3. Brief clinical validation mention  
4. Closing CTA  
5. Line-by-line spoken ↔ caption table + optional SRT block
