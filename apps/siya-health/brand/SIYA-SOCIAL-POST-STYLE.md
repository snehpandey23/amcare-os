---

## Design statement

**Siya Health social creatives should feel like a trusted clinician who also understands real life.**

Human warmth first. Clear teaching second. Brand + contact close the frame.

- Empathetic, modern, approachable medical authority  
- Not cold-clinical · not product-ad · not shame/fear marketing  
- Simple English · scannable · hopeful

---

## Color system (shared)

| Role | Use |
|------|-----|
| Navy / deep blue | Primary headlines & body |
| Magenta / plum | 1–3 keyword highlights, icons, soft CTAs |
| Soft lavender / cream / light blue | Fields, footers, callout fills |
| White / off-white | Breathing room |

**Keyword rule:** Highlight sparingly (usually 1–3 words). Prefer solid magenta/plum; pink→purple gradient OK on mechanism Template B.

---

## Two templates (same brand family)

### Template A — Awareness / human (DEFAULT for most statics)

**Drawn from sample images** (cervical checkup, future-self, independence, testosterone cover, ADHD productivity).

| Element | Rule |
|---------|------|
| Imagery | Real lifestyle photo **or** friendly illustrated people |
| Layout | Text left or top · human subject right/center · teaching mid · brand close |
| Type | Bold sans or refined serif for hooks; navy body; magenta keywords |
| Accents | Small hearts, soft botanical line art, optional **one** script word, optional **one** magenta circle “feeling” badge |
| Teaching | Icon rows / short checklists / light rounded callout boxes (allowed when they aid scanning) |
| Logo | Top-left on open frames **or** bottom footer lockup on awareness covers |
| Footer (preferred on awareness covers) | Logo + optional *Care. Compassion. Connection.* + `(215) 445-1244` + `www.siya.health` |
| Tone | Prevention, empowerment, recognition — invite care |

**Do not** default Template A to 3D anatomy / product bottles.

---

### Template B — Mechanism / education carousel

**For topics that need process explanation** (e.g. Minoxidil shedding cycle).

| Element | Rule |
|---------|------|
| Imagery | 3D medical illustration / timeline icons (follicle, dropper as educational prop) |
| Canvas | Off-white + soft lavender curves + magenta/purple corner waves |
| Type | Geometric sans · navy · pink→purple gradient keywords |
| Chrome | Bottom-left `n/5` pill · consistent margins |
| Logo | **Top-left only** — no background watermark |
| End slide | Evaluation / clinician CTA + phone + web |
| Tone | Trusted education — **not** product promotion |

---

## Logo rules

- Always show the real Siya Health® mark  
- **Never** a large background watermark  
- Template A: top-left *or* footer bar (match sample covers)  
- Template B: top-left only  

---

## Typography personality (controlled)

| Allowed | Limit |
|---------|-------|
| Navy + magenta keyword punch | Always |
| One script / handwritten emotional word | Max 1 per static |
| Hand-drawn heart / sparkle | Light touch |
| Emoji | Rare; only if sample-topic tone needs it (prefer none on clinical mechanism slides) |

---

## CTA hierarchy

1. Primary clinical: **Talk to a Clinician** / evaluation framing  
2. Contact: `(215) 445-1244` · `www.siya.health`  
3. Soft engagement (Template A only): Save / Share lines OK  
4. Never: Meet & Greet · Find the Right Starting Point · Start Here · Join Waitlist · Book with {Name} · Siya Circle as primary post CTA  

---

## Do / Don't

**Do**
- Lead with people and lived moments when inviting care  
- Use icons + short lists for “how to protect yourself / what to expect”  
- Keep magenta as the emotional accent, navy as authority  
- Close awareness covers with brand + phone + web  

**Don't**
- Force 3D follicle language onto women’s health / ADHD recognition / longevity awareness  
- Use full-bleed photo + handwritten text with **no** logo (Meeting Genius is empathy-only — not the brand lockup standard)  
- Crowd the first viewport with stats strips and promo chips  
- Promise outcomes or sell a product SKU
