# Instagram — AD-V-01 Reel

I start strong… then I vanish mid-task.

That pattern gets called laziness a lot.
Sometimes it’s a lifelong attention pattern showing up as follow-through collapse — not a moral failing.

Practical step:
For 7 days, log 3 tasks you start with energy. Note where momentum drops.
If it’s lifelong, take a validated ADHD screener — then talk to a clinician.
