## 1) Story spine (do not change without re-approval)

Open office noise → drained by noon → one support (quieter space) → practical asks (headphones / remote when allowed) → ask with documentation, not shame → soft CTA to the guide.

**Practical change carried in this reel:** Name your loudest workplace friction → ask what quieter-space options exist → if ADHD-related, ask a clinician what documentation they can provide.

**Claim ladder:** Lived noise/fatigue + one hedged support example + clinician-docs framing. No ADA guarantees, no approval %, no meds-as-accommodation.

## 3) Full VO script (read straight through)

> "Open office. Zero focus. With ADHD, constant noise can drain you — drained by noon.
> One support people discuss — a quieter workspace, or a cubicle instead of an open floor.
> Sometimes headphones. Sometimes remote days — when your role and policy allow it.
> Ask with documentation when you have it — not shame."

**Word count:** ~55 words · **Pace:** ~130–140 wpm → fits 22–24s of speech inside the 26–28s runtime (leaves headroom before end card).

**VO delivery notes:**
- Calm, warm, slightly slower on the hook line ("Open office. Zero focus.") — let it land.
- No dramatic pity tone; matter-of-fact + validating, like a knowledgeable friend.
- Do not add emphasis/inflection that implies guarantee ("will get you a quiet office") — keep "a support people discuss" neutral.

## 4) On-screen caption / text overlay spec (burn-in)

| Rule | Spec |
|---|---|
| Font | Georgia (headline beats) / Arial (support line, if any) — match brand lock, not HeyGen default caption font |
| Color | Navy `#001878` text on light captions; if overlaying on dark footage use cream `#F4EFE7` text with soft dark scrim strip behind it (never a hard black caption bar) |
| Accent | Magenta `#D81088` only on ≤3 words per scene (e.g. "Zero focus," "quieter workspace," "not shame") |
| Placement | Lower-third or center-safe zone — avoid top 15% (HeyGen/IG UI overlap) and bottom 20% (captions/CTA overlap) |

| Reject | Neon glow captions, meme-style Impact font, emoji stickers, animated bouncing text |

## 6) HeyGen build steps (no-avatar / stock-footage workflow)

1. Create new project → **Text-to-Video (stock footage)** mode — do **not** select an Avatar/Presenter template.
2. Paste the VO script (Section 3) into the script box, or upload as scene-by-scene text if HeyGen paces per-scene.
3. For each scene, either:
   - Use HeyGen's built-in stock library and search the **B-roll keywords** in the table above, or
   - Upload your own licensed/generated footage per scene (see Section 7 for sourcing notes) and assign it to that scene slot.
4. Add burned captions per Section 4 — disable HeyGen's default caption style and manually set font/color to match brand tokens (Georgia/Arial, Navy/Cream, Magenta accent ≤3 words).
5. Set aspect ratio **9:16**, duration target **26–28s**.
6. Add bed music per Section 5; duck under VO.
7. Insert the end card as a **static image** (built via `compose_*.py` compositor per Brand Style Lock — not a HeyGen auto-generated closing frame) so it matches the cream/navy/magenta system exactly.
8. Export MP4, no built-in watermark, review against the Section 8 checklist before posting.

---

## 7) Footage sourcing notes (real video, not illustration)

- Prefer **real people in real offices/homes** — warm, naturalistic lighting; avoid stock-photo "corporate handshake" energy.
- Diversity across gender/age within 22–55 adult range across scenes if using multiple stock clips (no single continuity actor required for this format, unlike the carousel).
- **Reject:** actors miming exaggerated stress (head-clutching, screaming at laptop), overly staged "diverse stock team meeting" clips, dramatic slow-motion sad walks, canned laughter-track office clips.
- If no suitable stock exists for a scene, it is acceptable to shoot a 3–5s handheld/tripod clip in a real office/home matching the description — keep it steady, natural light, no dialogue needed (VO carries the line).
