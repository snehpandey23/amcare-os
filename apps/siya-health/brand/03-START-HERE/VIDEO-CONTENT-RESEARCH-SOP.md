# Video Content Research SOP — Siya Health (v1)

```text
Status: v1 — verifying end-to-end on AD-V-01 (week of 2026-08-10)
Owner: Marketing / Editorial
Approver: Itika Thakur
Parents: INSTAGRAM-STATIC.md · 04-CREATIVE-SYSTEM.md · photography/ · medical-flags
```

## Why this exists

Carousel research (Reddit / PAA / blogs) is **not** enough for Reels. Video research must learn from **how high-performing short video actually looks and moves** on IG Reels / TikTok / YouTube Shorts — then feed our prompt → generate → feedback loop.

## Success for one run

1. One Insight ID chosen  
2. Research sheet filled (min criteria below)  
3. Video prompt pack written  
4. Draft frames + draft reel assembled  
5. Feedback captured (what to change next time)  
6. Tracker row updated  

**Time box (v1):** Research 45–60 min · Prompts 20 min · Generate/assemble 45–90 min · Feedback 15 min.

---

## Step 0 — Pick the Insight (5 min)

- Prefer a **new** recognition or education angle (not only polishing WH-R-02).  
- Must map to an existing Knowledge Product / spoke **or** explicitly mark “spoke TBD — organic educational only.”  
- Name Insight ID (`AD-V-01` style for video-first).  
- Write one **practical change** (required for company posts).  
- Fill `medical-flags.md` before generating claims.

---

## Step 1 — Platform scan (30–40 min)

Pick **one** primary platform for the research pass (default: **Instagram Reels**). Optionally note 2–3 YouTube Shorts / TikTok comps.

### How to find comps

1. Search topic keywords + `#ADHD` / condition terms (no stalking patients).  
2. Prefer accounts with **strong views or saves** on *this* topic — not only follower count.  
3. Save **5–10** competitor/peer reels into the pack research log.

### Per-reel log (required fields)

| Field | What to capture |
|-------|-----------------|
| URL / account | Where it lives |
| Hook (0–3s) | Exact opening line or visual |
| Format | Face-cam · VO + B-roll · text-on-illustration · sketch |
| Beat structure | Rough timestamps |
| On-screen text style | Few large words vs dense |
| What earned attention | Honest guess: humor, recognition, myth-bust, list |
| Siya-safe? | Y/N — would we ever say this? |
| Steal / adapt | One technique only (not their claim) |
| Avoid | Fear, self-diagnose guarantee, dose talk, fake urgency |

### Minimum bar to proceed

- ≥5 logged reels  
- ≥3 **Siya-safe** techniques listed  
- 1 clear **hook pattern** chosen for our draft  

---

## Step 2 — Angle lock (10 min)

Write in `research/ANGLE.md`:

1. **Recognition moment** (one sentence — “That’s me.”)  
2. **One concept only** (no second disease in the same reel)  
3. **Practical change** (screener / log / ask clinician — specific)  
4. **Soft CTA mix** (blog · free screening · Meet & Greet — pick one for this reel)  
5. **Hard bans** for this piece  

---

## Step 3 — Video prompt pack (15–20 min)

Create `prompts/video-prompts.md` using the **style lock**:

```text
Soft warm-toned digital illustration, painterly slightly hand-drawn,
subtle textured cream paper background, muted earthy pastels, gentle lighting,
emotionally expressive but calm, Siya Health quiet submerged logo top-left,
9:16 or 4:5 frames as specified, no stock photography look, no badge walls,
no medical clipart, no harsh contrast, no purple SaaS glow.
```

For a **30s illustration reel**, specify **4–6 frames**:

| Frame | Time | On-image text (few words) | Visual |
|-------|------|---------------------------|--------|
| 1 Hook | 0–3s | … | … |
| 2 Beat | … | … | … |
| … | … | … | … |
| End | last 3s | practical change or path | quiet end card |

Also write **spoken / caption script** in `reel.md` (even if VO is later).

---

## Step 4 — Generate → assemble (45–90 min)

1. Generate frames into `frames/` (or `ready-to-post/` stills).  
2. QA vs `INSTAGRAM-STATIC.md`: submerged logo, quiet footer on stills used as posts, no chrome badges.  
3. Assemble 9:16 draft with slow Ken Burns + crossfades (same pattern as WH-R-02) → `video/[ID]-reel.mp4`.  
4. No audio required in v1 — add music in-app at post time.  
5. Write platform captions under `captions/` (IG Reel, Facebook, LinkedIn Company, X, Pinterest, `ALL-PLATFORMS.md`). **No Founder LinkedIn unless requested.**

---

## Step 5 — Feedback (15 min) — required

Approver (**Itika**) fills `research/FEEDBACK.md`:

- Hook clear in 1s?  
- Recognition without self-diagnose?  
- Practical change memorable?  
- Visual density OK vs WH-R-02 quiet field?  
- Prompt changes for next run (add / delete / tighten)  

If feedback is “process broken,” update **this SOP** the same day — do not only fix the one reel.

---

## Step 6 — Tracker + handoff

Add/update row in `04-Content-Tracker/Siya-Content-Tracker-Posts.csv` (and Google Sheet when live).  
Status path: Draft → Ready → Scheduled → Published.
