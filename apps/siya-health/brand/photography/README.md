# Siya Health — Photography Library

This is a **brand asset**, not a website feature.

Every future page, blog post, landing page, and social graphic should pull from this library instead of searching for new stock images each time.

---

## North star

Images are not decoration.

They solve a psychological problem:

> Make patients feel seen before asking them to trust you.

If an image only says “healthcare,” it does not belong here.

If it makes someone think “that’s exactly me,” it does.

---

## Visual language

Every approved asset should feel like it came from the same editorial shoot:

- Warm natural light
- Real adults (not stock-smiling doctors)
- Authentic expressions
- Everyday environments (home, kitchen, desk, bed, commute)
- Minimal visual clutter
- Consistent warm color grading
- No competitor branding, fake clinic logos, or staged clipboard portraits

**Avoid:** Wellspring / MedConnect / Power Telehealth stock, AI-looking posed teams, doctors smiling at camera, decorative abstract medical art.

---

## How to use

1. Pick the **recognition category** that matches the section’s emotional job.
2. Choose an asset from that folder (see `INVENTORY.md`).
3. For the website, publish/copy into `assets/images/` only when needed for a URL — keep this library as the source of truth for selection.
4. Prefer an existing library asset over a new stock search.
5. If nothing fits, mark the gap in `INVENTORY.md` and commission or shoot — do not fill with generic healthcare stock.

## Categories

| Folder | Recognition job |
|---|---|
| `physician-listening` | Being heard in a calm clinical conversation |
| `patient-overwhelmed` | Constant overwhelm, mental load, burnout |
| `morning-fatigue` | Exhausted mornings, energy that never returns |
| `unfinished-work` | Can’t finish tasks, lost keys, time blindness |
| `virtual-consult` | Home telehealth that feels human |
| `family-medicine` | Everyday primary care, whole-person follow-up |
| `metabolic-health` | Weight, food noise, effort that doesn’t stick |
| `womens-health` | Hormones, cycles, midlife health |
| `mens-health` | Energy, drive, longevity, men’s metabolic care |
| `sleep` | Racing mind at night, poor recovery |
| `prevention` | Steady, proactive care — not crisis medicine |

---

## Workflow for new photography

1. Shoot or commission into the matching category folder here.
2. Name files: `{category}-{short-moment}-{YYYY}.jpg` (example: `morning-fatigue-coffee-counter-2026.jpg`).
3. Update `INVENTORY.md` status → `approved`.
4. When used on the site, copy/export a web-optimized version into `assets/images/` and reference that public path.

---

## Status legend (in inventory)

- **approved** — safe for Siya surfaces
- **seeded** — useful interim editorial; replace when dedicated shoot exists
- **needs-shoot** — category gap; do not fill with generic stock
