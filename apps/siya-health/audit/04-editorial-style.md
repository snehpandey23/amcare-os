# Website Cohesion Audit v1.0 — Editorial Style

## Publication standard

Siya should read like one clinically responsible, plain-language publication: direct, calm, specific, and helpful. It should not sound like a search template, a software company, or an overpromising clinic.

## P0

### EDT-001 — Incoherent published prose

`/blog/adult-adhd-treatment-california-2026` contains garbled, keyword-stuffed sentences. This is a publication-quality and trust failure, not a minor copy edit.

### EDT-002 — Topic-inappropriate clinical language

The ADHD “childhood versus adult onset” preparation paragraph appears on 12 non-ADHD guides. Four unrelated pages also contain a GLP-1 emergency branch. These blocks violate both voice and clinical context.

## P1

### EDT-003 — Formulaic guide grammar

All Answer pages use a near-identical sequence. Predictability is useful, but “misconceptions,” “decision support,” and “coordinating care” must be optional rather than required slots.

### EDT-004 — Reused city FAQs

Approximately 13 city treatment pages repeat the same online-diagnosis answer. Preserve factual consistency, but rewrite examples and local context or consolidate the pages.

### EDT-005 — CTA prose exceeds editorial role

Some pages repeatedly switch from education to screening, booking, chat, pricing, and geography. Editorial content should transition once into care, with one primary next step.

## Locked style choices

- Brand name: **Siya Health** in public copy. Use the legal entity name only where legally required.
- Voice: clinician-informed, plain language, no hype.
- Reading level: approximately grades 7–9 for general patient content.
- Headings: sentence case.
- Oxford comma: **use it**.
- Exclamation marks: avoid in clinical/editorial copy.
- Bold: use for scan anchors, not full sentences or promotional emphasis.
- Bullets: parallel grammar; use periods only when items are complete sentences.
- Quotes: use curly quotation marks in authored prose; preserve exact source quotations.
- “Meet & Greet”: use one spelling and capitalization everywhere.
- Prices: source only from the canonical pricing registry/page; never hard-code editorially.
- Claims: separate education from diagnosis and treatment recommendations.

## Required page-level edit

Before publication, an editor must answer:

1. Does every section advance this page’s question?
2. Is any paragraph reusable on 20 unrelated pages? If yes, is it true chrome or template bleed?
3. Does the care transition feel earned?
4. Are all clinical details specific to this topic?
5. Would this page still make sense if all SEO keywords were removed?

## Acceptance threshold

- Zero incoherent or keyword-stuffed paragraphs.
- Zero cross-topic clinical appenders.
- One locked terminology list for services, tools, providers, prices, and states.
- Every page passes the Content QA Checklist before publication.
