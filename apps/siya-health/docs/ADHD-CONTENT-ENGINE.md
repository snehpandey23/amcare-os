1. Does this become the **definitive page** for a topic Siya must own? **OR**

## Quality bar (anti-encyclopedia)

A 8.5 medical / 7.5 SEO encyclopedia article is **not enough**. Target **9.5+** after:

| Must include when relevant | Why |
|----------------------------|-----|
| Prevalence / “how common” early | Google + readers trust magnitude |
| Comparison table (A vs B) | Featured snippet |
| Myth → Reality box | Social + clarity |
| Practical day / lived scene (not tip laundry lists) | Conversion imagination |
| Medication deep-dive when searched (e.g. Vyvanse + BED) | Commercial informational |
| What happens in evaluation (Siya-specific process) | Trust → booking |
| Entity H2s that match secondary KWs | Ranking diversity |
| EEAT block (reviewer, credentials, last reviewed, refs) | Healthcare trust |
| Closing that reframes the reader’s question toward ADHD eval | Natural conversion |

**Tone:** Clinically accurate, adult, non-shaming, readable. No willpower-blaming. No invented studies.

Match mid-article CTAs to funnel. Executive dysfunction ≠ ADHD cost page CTA.
