# Content QA Checklist (pre-publish)

Every article/guide must pass before publishing. One NO = fix before ship.

| # | Check | Question | Pass |
|---|-------|----------|------|
| 1 | **Flow** | Does every section naturally follow the previous one? | ☐ |
| 2 | **Relevance** | Does every CTA relate directly to the topic? | ☐ |
| 3 | **Geography** | Does the page avoid introducing states that aren't relevant? | ☐ |
| 4 | **Repetition** | Is every paragraph unique (not duplicated elsewhere)? | ☐ |
| 5 | **Navigation** | Is nothing here that a related-article card would do better? | ☐ |
| 6 | **User intent** | If I searched this topic, would this page help me? | ☐ |
| 7 | **Separators** | No repeated horizontal rules; whitespace separates sections? | ☐ |
| 8 | **Links** | Clinical-care CTA ≤ 3 contextual links + one button? | ☐ |
| 9 | **Disclaimers** | Educational/not-a-diagnosis where tools or claims require it? | ☐ |
| 10 | **Assembly rule** | Would a human editor choose every block on this page? | ☐ |

Tie-in: `docs/CONTENT-ASSEMBLY-SYSTEM.md` (every page earns every section).
