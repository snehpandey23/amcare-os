# Siya Visual Inspiration Board

**Purpose:** Pattern recognition only — not layout cloning.  
**Design target:** More human than Hims · More premium than typical telehealth · Less clinical than hospital sites · More trustworthy than wellness influencers.

For each reference: Emotion · Premium cues · Adopt · Avoid.

---

## 1. Apple Health / Apple product marketing

| Lens | Notes |
| --- | --- |
| **Emotion** | Calm confidence; technology as quiet support |
| **Premium** | Huge whitespace; one idea per screen; photography does the selling |
| **Adopt** | Hero budget discipline; one headline + one supporting line; generous margins |
| **Avoid** | Cold gadget-first feel; Siya must stay human/physician-first |

---

## 2. Headspace

| Lens | Notes |
| --- | --- |
| **Emotion** | Soft, caring, psychologically safe |
| **Premium** | Soft color fields; friendly illustration/photo balance; unhurried pacing |
| **Adopt** | Warmth without clutter; gentle section transitions; short supportive copy |
| **Avoid** | Cartoon-heavy wellness aesthetic; overly playful for clinical trust |

---

## 3. Calm

| Lens | Notes |
| --- | --- |
| **Emotion** | Quiet; permission to slow down |
| **Premium** | Dark/light atmospheres with restraint; ambient photography |
| **Adopt** | Breathing room; minimal competing CTAs; serene imagery |
| **Avoid** | Full dark-mode homepage (Siya stays light/warm); wellness-app vibe over medical care |

---

## 4. Hims / Hers (feeling only)

| Lens | Notes |
| --- | --- |
| **Emotion** | Modern, approachable, “this is for me” |
| **Premium** | Strong product photography; bold type; clear conversion path |
| **Adopt** | Clarity of next step; confidence in packaging |
| **Avoid** | DTC convenience brand energy; product-grid denseness; “get meds fast” framing; cloning their card layouts |

---

## 5. One Medical / boutique primary care sites ⭐ primary study reference

| Lens | Notes |
| --- | --- |
| **Emotion** | Professional care with hospitality — closer to Siya’s space than Hims |
| **Premium** | Real clinicians; clean typography; membership clarity |
| **Adopt** | How it presents physicians; explains care; balances warmth with clinical credibility |
| **Avoid** | Corporate membership-site density; insurance-portal chrome; cloning layouts |

**Why it matters for B+A+:** One Medical optimizes for **relationships and physician trust**. Hims optimizes for scale and convenience. Study the former; do not become the latter.

## 8. Cerebral / Done / Circle Medical (cautionary)

## 10. Local physician / concierge practice sites (best-in-class)

| Lens | Notes |
| --- | --- |
| **Emotion** | “My doctor’s practice” |
| **Premium** | Real faces; credentials without clutter; simple booking |
| **Adopt** | Face-forward trust; plain-language process; one clear CTA |
| **Avoid** | Template WordPress medical themes; clipart + stock stethoscopes |

---

## Synthesis — Siya’s unique target

| Dimension | Direction |
| --- | --- |
| vs Hims | More human, less productized |
| vs startup telehealth | More premium, less purple-SaaS |
| vs hospital | Less clinical chrome, more warmth |
| vs influencers | More credentialed, less lifestyle theater |

**North star feeling:** A real physician welcoming you — calm, warm, premium, trustworthy.

**Homepage reference rule:** Whatever we ship on `/` becomes the only design language for later pages. Do not freestyle per page.
