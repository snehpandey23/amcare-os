## Minimum bio requirements for adding a new provider

Before provider #4 can go live, collect:

1. Legal display name, credentials, role, headshot + alt text
2. Active license states with verification source (no invented license numbers)
3. Board certifications with verification status
4. Medical school, residency, fellowship (if applicable)
5. Clinical focus, services, patient-fit, care philosophy (approved copy)
6. Booking link, accepting-new-patients status per state
7. Profile last-updated date and credential verification date
8. Signed consent for headshot, profile publication, and testimonial use
9. No patient volume, rating, or award claims without documented source
