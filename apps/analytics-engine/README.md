# Analytics Engine

Reports, insights, and data visualization for operations and compliance.

## Features

- **Reports**: Generate and view operational reports
- **Insights**: Data-driven insights and analytics
- **Dashboards**: Customizable data dashboards
- **Compliance Reports**: HIPAA compliance reporting
- **Export**: Export data in various formats

## Development

```bash
npm run dev
```

Runs on port 3004 (configurable via ANALYTICS_ENGINE_PORT)
