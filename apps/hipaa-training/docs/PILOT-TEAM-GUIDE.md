## Daily flow (everyone · staff)

1. **Sign in** with work email + password from your admin invite.
2. Tap **Start shift** (header) if you don’t yet see Working / Break / Focus.
3. Top right: confirm **Working**. Use **Break** / **Focus** / **Back to working** as needed. **Focus** = quieter My day (learning nudges pause).
4. **My day** (home) = **Ask (Assist chat)** + **Today’s tasks**. Ask is not a separate nav item.
5. **Team** = who’s Working/Break/Focus/Off + **shift handoffs** today.
6. **End shift** when you finish (opens optional handoff) — different from **Sign out** (ends login only).

## Feedback (short)

- **👍/👎** = was this Assist reply helpful? (log only)  
- **Notify owner** = missing approved **policy** guide — not UI bugs  
- Weekly lead check-in = **Marketing / Clinical / Compliance leads** only  

## Department SOP leads

## Admins

- **Admin** nav → invite, task board, SOP review.  
- Admin My day = Founder Talk / This week’s plan (no staff shift bar).  
- Full cards: `TRAINING-ADMIN-PACK.md`.

## Support

Wrong password → admin reset on **Admin → Team → Edit**.  
Tasks missing → admin checks **Task board** and department lead assignment.  
“Where is …?” → ask on **My day** (Assist already answers chrome how-to).
