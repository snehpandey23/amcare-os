# Staff Dashboard

Daily task management, KPIs, and staff interface for healthcare operations.

## Features

- **Daily Tasks**: Task assignment and tracking
- **KPIs**: Key performance indicators dashboard
- **Staff Management**: Team overview and management
- **Quick Actions**: Common operations shortcuts
- **Notifications**: Real-time updates and alerts

## Development

```bash
npm run dev
```

Runs on port 3001 (configurable via STAFF_DASHBOARD_PORT)
