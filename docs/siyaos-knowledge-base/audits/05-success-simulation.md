# Audit V5 — Success simulation (one workday)

Run **after** V1 content is materially better (~40–50 content score) and **V4 = 0 unsafe**. Goal: adoption and speed, not just correctness.

---

## ROLE

You are our highest-performing employee.

Use **Siya Assistant exclusively** for an entire simulated workday.

Complete as many **realistic tasks** as possible (pick a role: MA/coordinator, marketing, ops, accounts).

Do not cheat by opening policies you already know — only what the assistant (+ linked approved sources) provides.

---

## TASK MIX (examples — do 8–15 tasks)

- Find escalation path for a billing dispute  
- Draft plan for Instagram carousel (company voice)  
- Look up late-cancel policy language  
- Request reimbursement steps for software purchase  
- Triage “family caller asking about charges”  
- Find why homepage CTA is Meet & Greet  
- Look up portal chat SLA  
- Report suspected privacy issue (no PHI in chat)  
- Find content QA before publish  
- Onboarding question: tools access  

---

## FOR EACH TASK

| Field | Value |
|-------|--------|
| Task | What you tried to complete |
| Outcome | **SUCCESS** / **FRICTION** / **CONTEXT SWITCH** |
| Context switches | Count tools/channels outside Siya Assist (Slack, Drive, Zoho, email, manager, …) |
| Time estimate | Faster / same / slower than old habit |
| Bucket gap | If friction or switch — which bucket (1–5) was missing? |
| Delight | Anything that felt surprisingly good? |

**SUCCESS** — assistant enough to finish from approved knowledge.  
**FRICTION** — started in assistant but incomplete / vague / had to guess.  
**CONTEXT SWITCH** — abandoned assistant for another system to finish.

---

## AGGREGATE METRICS

- **Median context switches per task** (target → 1 over time)  
- **Success rate** = SUCCESS / total tasks  
- **Abandon rate** = CONTEXT SWITCH / total  
- Top 5 friction themes  
- Top 5 missing automations (“assistant should link X or pre-fill escalation”)  
- Delight opportunities  

---

## FINAL REPORT

Include dual scores if you re-ran spot-check questions, plus:

- Successes  
- Friction points  
- Context switches (table)  
- Missing automations  
- Delight opportunities  
- **Ship readiness (feel):** Would you default to Siya Assist tomorrow? (Yes / Not yet — why)

Append summary row to `score-log.md` (V5 columns optional: success rate, median switches).
